# Triage Labels

Map canonical triage roles to the strings used in local `Status:` lines.

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified, ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use the local status corresponding to the role requested by a skill.
Edit the Local status column to change the vocabulary later.
